Type inference: var still has a type

Dart infers a variable’s static type from its initial value: var year = 2026; becomes int; var label = 'Dart'; becomes String. Reassigning the same type is allowed; changing its type is not. By contrast, var something; without an initializer is inferred as dynamic in this situation.

02 · TYPE INFERENCEvar hours = 4;The type is inferred as int.
03 · FINALfinal startedAt = DateTime.now();Assigned once at runtime.
04 · CONSTconst lessons = 3;Known at compile time.

Type inference with var — not dynamic typing

Type inference means Dart infers a variable's static type from its initializer. var trainee = 'Maya'; becomes a String: you can assign another string, but not an integer. var x; without an initial value usually gives dynamic; avoid this in beginner code. final is assigned once, while const is known at compile time.

STEP 05 · DART'S SOUND NULL SAFETY23 MIN

Null Safety: make missing values explicit

You already know null from C# and JavaScript. Dart's important difference is that non-nullable is the default: the analyzer makes you handle missing values before accessing their members.

?
WHY THIS MATTERS · Flutter and Dart Fundamentals, CHAPTER 2

The missing-value bug we want to catch before the app runs

A program reads a username, but the value is missing. Calling .length on null would cause a runtime error. Dart prevents an unchecked member access on a nullable value during analysis, before you ship the Flutter app.

This is not about forbidding null. It's about explicitly showing where absence is possible and handling it.

01 · MAY BE MISSINGString? nameNullable type
→
02 · CHOOSE A SAFE ROUTEif / ?. / ??Check, skip or default
→
03 · USE IT SAFELYname.lengthKnown non-null or handled

1. The type decides whether null is allowed

NON-NULLABLE

String name = 'Mira';

Always a String. name = null; is an analyzer error.

NULLABLE

String? name = null;

Either a String or null. Before name.length, you must handle the missing-value case.

2. What does the analyzer reject, and what does it accept?

Unsafe: String? name = null; followed by name.length is rejected. Safe: after if (name != null), Dart's flow analysis knows name is non-null inside the checked branch. A declared String cannot be assigned a possibly null String? without handling it.

main.dart · Null check + flow promotion
void main() {
  String? name = 'Mira';
  // print(name.length); // Analyzer error without a check
  if (name != null) {
    print(name.length);   // 4: promoted to String here
  } else {
    print('Name not supplied');
  }
}

A safe check is usually clearer than forcing an assertion. Note: a nullable variable is different from an uninitialized non-nullable variable.

3. Five operators: five distinct jobs

?

Nullable type

String? label;

Allows the value to be a String or null. This ? is a type marker, not the ternary operator.

?.

Safe access

label?.length

Accesses a member only when the receiver is non-null; otherwise the expression evaluates to null.

??

Fallback value

label ?? 'Guest'

Returns the original value if present; otherwise returns the right-hand fallback. An empty string is not null.

??=

Assign if missing

label ??= 'Guest';

Assigns the fallback only if the variable currently contains null. Unlike ??, this changes the variable.

!

Force non-null

label!.length

Asserts the value is not null. If you're wrong, this throws at runtime. Prefer a check or a fallback.

Book vs extension: ?, ?., ?? and ! are explained in Flutter and Dart Fundamentals, Chapter 2. ??= is a small extra from the official Dart operators reference. The ternary condition ? yes : no is a separate syntax, reviewed earlier.

void main() {

STEP 06 · COMPARISONS & LOGIC09 MIN

Write conditions that evaluate to true or false

Before making a decision, Dart needs a Boolean condition. You already know the logic — refresh the symbols and the evaluation rules.

Comparisons produce bool

==equal value
!=not equal
> / >=greater than / at least
< / <=less than / at most

Watch the difference: = assigns, whereas == compares.

Logical operators combine conditions

&&AND · both must be true
||OR · at least one must be true
!NOT · reverses true / false

Short-circuiting: && skips its right side if the left is false, and || skips its right side if the left is true. This matters when a check could otherwise fail.

Flutter and Dart Fundamentals · CHAPTER 3 + OFFICIAL DART OPERATORS

Operator precedence · أولويات العمليات

When an expression contains several operators, precedence determines which groups are evaluated first. The levels below are ordered from higher priority to lower priority.

01Grouping / unary( )!Group explicitly; negate a Boolean
02Multiply / divide* / ~/ %Before addition and subtraction
03Add / subtract+ -Arithmetic result first
04Relational comparison> >= < <=Compare arithmetic values
05Equality== !=Test equality / inequality
06Logical AND&&Before logical OR
07Logical OR||Combines alternative conditions

Lower down the order: ?? (if-null), condition ? a : b (ternary), and = (assignment). We use them in the conversion and decision-making examples. Use parentheses for clarity.

WITHOUT PARENTHESES3 + 2 * 4 > 10 && trueResult: true
WITH EXPLICIT GROUPING((3 + (2 * 4)) > 10) && trueSame result: true

Best practice: Add parentheses when they help readers understand your intention; don't make a teammate memorize the full precedence table. Official Dart operator table ↗

import 'dart:io';
void main() {

    stdout.write('Score (blank to quit): ');

calculator.dart · Dart CLI with dart:io
import 'dart:io';

void main() {
  stdout.write('First number: ');
  final rawA = stdin.readLineSync();
  stdout.write('Second number: ');
  final rawB = stdin.readLineSync();
  final a = double.tryParse(rawA ?? '');
  final b = double.tryParse(rawB ?? '');
  if (a == null || b == null) {
    print('Invalid input. Enter valid numbers.');
    return;
  }
  print('Sum: ${a + b}');
  print('Difference: ${a - b}');
  print('Product: ${a * b}');
  print(b == 0 ? 'Cannot divide by zero' : 'Quotient: ${a / b}');
}

LOCAL CODE · RANDOM TARGET + REAL KEYBOARD INPUT

Read guesses from the terminal and keep asking until the player succeeds.

guessing_game.dart · Dart CLI with dart:io and dart:math
import 'dart:io';
import 'dart:math';

void main() {
  final target = Random().nextInt(100) + 1;
  var attempts = 0;
  print('Guess the number (1 to 100).');
  while (true) {
    stdout.write('Your guess: ');
    final raw = stdin.readLineSync();
    if (raw == null) break; // Input stream closed.
    final guess = int.tryParse(raw);
    if (guess == null) {
      print('Please enter a whole number.');
      continue; // Invalid input does not count.
    }
    attempts++;
    if (guess < target) {
      print('Too low!');
    } else if (guess > target) {
      print('Too high!');
    } else {
      print('Correct in $attempts attempts!');
      break;
    }
  }
}

main.dart · Guessing Game · DartPad-ready
void main() {
  // Scripted guesses replace terminal input in DartPad.
  const target = 50;             // Change this first.
  final guesses = ['oops', '20', '70', '50'];
  var attempts = 0;
  for (var i = 0; i < guesses.length; i++) {
    final guess = int.tryParse(guesses[i]);
    if (guess == null) {
      print('Invalid entry: ${guesses[i]}');
      continue;
    }
    attempts++;
    if (guess < target) {
      print('$guess: Too low!');
    } else if (guess > target) {
      print('$guess: Too high!');
    } else {
      print('$guess: Correct in $attempts valid attempts!');
      break;
    }
  }
